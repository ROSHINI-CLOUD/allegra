## If you read only three things
1. **`01-GOAL.md`** — what winning looks like and what the rules require
2. **`03-DELIVERY.md`** — what you're doing in the next four hours
3. **`docs/api-contract.md`** — so you're never blocked on a teammate

## The three that actually lose hackathons
- **Nothing deployed until late** → Ship It scores zero. URL live by T+6.
- **Seek silently broken** → the demo falls apart on camera. Automated test in the first 4 hours.
- **Rushed video** → Presentation is a quarter of the score. Filming starts T+22.

All three are preventable by doing the boring thing early.
