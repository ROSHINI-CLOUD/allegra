  <action>
From `apps/mobile`, run:
```
grep -rnE "^\s+\w+: \{[^}]*\bheight: (2[0-9]|[3-9][0-9]|1[0-4][0-9])\b" src/screens src/components --include=*.tsx
```
This lists style entries with a fixed height from 20 to 149. Skip `src/ui/`, Skia canvases, artwork squares, progress bars, dividers, icons and thumb sizes. Skip the owner-locked files in PLAN.md section 0.
For each remaining hit, open the JSX that uses the style and decide:
- **fix**: the element is a row, button, chip or input with a `Text` child that can wrap or grow, and it has no `numberOfLines={1}` on every text child.
- **skip**: the text is `numberOfLines={1}` and truncates on purpose, or the box holds no text.
- **device**: unclear; add to the device checklist in phase 4.
Write `TEXT-SCALE-FINDINGS.md` as a table: `file:line | style name | what it wraps | decision | reason`. End with the count of fix / skip / device.
If there are more than 12 "fix" rows, stop and report; choose the six with the most visible screens (Library, Search, Playlists, Settings, Now Playing controls first) and mark the rest "deferred".
